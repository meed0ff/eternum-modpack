# Репозиторий сборки AstralForge (Minecraft 1.21.1 + NeoForge 21.1.267)

Этот репозиторий хранит манифест сборки, конфигурационные файлы и кастомные моды для лаунчера **AstralForge**.

---

### Архитектура оптимизации трафика
1. **Моды с Modrinth:** Скрипт `generate_manifest.py` при запуске автоматически определяет, есть ли ваши моды на Modrinth по их хешам. Если есть — ссылки в `manifest.json` прописываются напрямую на **Modrinth CDN** (`cdn.modrinth.com`). Это экономит место в GitHub и обеспечивает игрокам максимальную скорость скачивания.
2. **Кастомные моды и конфиги:** Те моды, которых нет на Modrinth, а также вся папка `config/` хранятся прямо в этом репозитории и скачиваются через `raw.githubusercontent.com`.

---

### Как обновить сборку для игроков:
1. Отредактируйте `repo_config.json`, указав ваше имя пользователя GitHub (`repo_owner`), название репозитория (`repo_name`) и IP вашего сервера (`server_ip`).
2. Положите нужные моды `.jar` в папку `mods/`.
3. Положите конфигурационные файлы в папку `config/`.
4. Запустите генератор манифеста:
   ```bash
   python3 generate_manifest.py
   ```
5. Закоммитьте и отправьте изменения на GitHub:
   ```bash
   git add .
   git commit -m "Update modpack"
   git push origin main
   ```
6. Игроки при следующем запуске лаунчера автоматически получат новые файлы!
